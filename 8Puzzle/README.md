# 8Puzzle

Implementação do problema dos oito números em um tabuleiro 3×3, desenvolvida como trabalho acadêmico da disciplina de Algoritmos II.

## Funcionamento

O programa representa o tabuleiro por uma matriz 3×3 e utiliza valores para identificar as peças e a posição vazia.

## Estrutura do projeto

- `include/` — arquivos de cabeçalho.
- `src/` — arquivos-fonte da implementação.
- `Makefile` — configuração da compilação.

## Compilação

Com o `make` instalado, execute na pasta do projeto:

```bash
make
```

## Execução

Após a compilação, execute o arquivo gerado pelo `Makefile`.

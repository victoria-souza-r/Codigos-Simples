# Códigos Simples

Repositório com exercícios e trabalhos desenvolvidos ao longo das disciplinas iniciais de programação.

## Conteúdos

- **8Puzzle** — implementação do problema dos oito números.
- **Polinômios** — implementação de operações com polinômios em C++.
- **Labirinto** — implementação de um algoritmo de busca em profundidade (DFS) com recursividade e backtracking para encontrar caminhos em labirintos, utilizando arquivos para leitura e gravação.
